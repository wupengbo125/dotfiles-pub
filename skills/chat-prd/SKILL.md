# Chat PRD

通过交互对话（Grill 模式）将用户模糊的想法转化为结构化的 OKF 格式需求方案书（`docs/prd/<slug>.md`）。

## 核心流程

### Step 1: 交互访谈与需求 Grill

使用 `/grill-me`（依赖 `grill-me` skill）驱动与用户的多轮对话：
> **注**：若 `grill-me` 技能未安装，请指引用户运行项目根目录下的 从https://github.com/mattpocock/skills 安装。

1. **复述理解**：用精炼的语言复述当前掌握的需求全貌。
2. **追问盲区**：针对背景目的、核心流程、边界（不做什么）、异常逻辑提出精准问题。
3. **循环迭代**：重复上述过程，不断消除模糊点。

- **完成标准**：用户明确回应“需求已清晰”或“没有补充”，且背景、核心行为、边界均已确认。

### Step 2: 实施方案推演

结合现有项目结构推演技术实施思路：
1. 确定涉及的核心模块或分步步骤。
2. 明确实现路径与高层架构方案。

- **完成标准**：提炼出包含至少 3 个高层实现步骤的框架方案。

### Step 3: 生成 PRD 方案书

读取同目录下的 `PRD-TEMPLATE.md` 模板，在项目中创建并填写包含 OKF Frontmatter (`type: PRD`) 的 `docs/prd/<slug>.md`。

- **完成标准**：`docs/prd/<slug>.md` 文件创建完成，填满背景、需求描述、边界、待确认事项及实施方案所有章节。

### Step 4: 同步生成 ADR 决策文档

若需求讨论中产生了明确的技术选型、架构方案抉择或重大业务取舍，读取同目录下的 `ADR-TEMPLATE.md` 模板，在 `docs/adr/<slug>.md` 中生成对应的架构决策记录。

- **完成标准**：`docs/adr/<slug>.md` 创建完成，记录选定方案、备选方案及优劣权衡。
